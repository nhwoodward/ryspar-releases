# Ryspar releases

Downloads and update feeds for [Ryspar](https://ryspar.dev), a coding-agent workspace for desktop, web and mobile.

- **Download:** [ryspar.dev/download](https://ryspar.dev/download/) picks the right installer. Every build is also on the [releases page](https://github.com/nhwoodward/ryspar-releases/releases).
- **Verify:** each release lists a `SHA256SUMS` file for its assets.
- **Updates:** the desktop app, the `ryspar` CLI and the background service update from the releases here.

This repository holds binaries only. Ryspar's source is private. `appcast.xml` is an empty feed kept for installs of the earlier macOS app.
